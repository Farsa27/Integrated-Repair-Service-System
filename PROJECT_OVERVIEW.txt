  PROJECT OVERVIEW
═══════════════════════════════════════════════════════════════════════════════

RepairHub is a professional marketplace platform that connects customers
with verified repair and maintenance service professionals.

Key Capabilities:
  ✓ User authentication (email/password + Google OAuth)
  ✓ 10+ repair service categories
  ✓ Professional profiles with ratings & reviews
  ✓ Appointment booking system
  ✓ Price negotiation workflow
  ✓ Admin management dashboard
  ✓ Responsive mobile-first design
  ✓ Production-ready deployment


═══════════════════════════════════════════════════════════════════════════════
  QUICK START GUIDE
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Read Documentation
  → Open INDEX.md or PROJECT_SUMMARY.md

STEP 2: Setup Environment
  → Follow QUICKSTART.md (5 minutes)

STEP 3: Run Locally
  $ ./setup.sh
  
  Terminal 1:
  $ cd backend && npm run dev
  
  Terminal 2:
  $ cd frontend && npm start

STEP 4: Visit Application
  → http://localhost:3000
